# Проверки графика Finam

`test_finam_delta_chart.py` создаёт временные дневные ZIP и вызывает расчёт из `finam_delta_bar_chart/chart.py`. Проверяется одно окно из 20 предыдущих будних сессий с тиками для среднего объёма и порога дельты, в том числе при построении графика с субботы по понедельник. Остальные проверки охватывают пустые дни, недостаточную историю, совпадающие времена закрытия, смену сессии и частоту направленных сделок. Используется стандартная библиотека Python и локальное расчётное ядро.

Запуск из корня `pj31_delta_ts`. Параметр `-s` задаёт каталог тестов, `-p` выбирает файл, `-v` включает подробный вывод.

Тесты прогресса проверяют оба счётчика на диапазоне с пустым и отсутствующим архивами, а также расчёт оставшегося времени и его сброс в начале следующего этапа.

При отсутствии папки тиков или ZIP за выбранную дату проверяется полный путь в сообщении об ошибке при относительном `--input-root`.

Тесты дневного кэша создают базу рядом с временными ZIP. Они проверяют повторное открытие и выборку части диапазона без чтения тиков, возобновление прерванного расчёта, обновление среднего после изменения, добавления или удаления буднего ZIP и независимость буднего окна от воскресного архива.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_finam_delta_chart.py -v
```

`test_standalone_chart.py` переносит код графика во временный каталог и проверяет запуск с `--help` напрямую и через `python -m` без соседних проектов. Отдельная проверка имитирует `ru_RU` в дочерних процессах и подтверждает открытие обычного окна Qt и экспорт PNG на тестовых ZIP.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_standalone_chart.py -v
```

`test_manual_backtest.py` проверяет раскрытие свечей, команды окна Qt, входы и выходы на совпадающих временных метках, откат, защиту существующего CSV и повтор команды после ошибки сохранения. Для открытых позиций проверяются прибыль и убыток по текущему открытию и последнему закрытию, для закрытых — результат по цене выхода и его отмена. Проверки CSV сверяют четыре индикатора предыдущего завершённого бара и пустые значения при первом входе в новую сессию. На тестовых ZIP отдельно проверяется загрузка бэктеста из `src` при запуске `chart.py --backtest` напрямую и через `python -m`. Для проверки используются временные файлы и окно Qt в режиме без экрана.

Для `close_buy_rate` и `close_sell_rate` проверяются одновременный выход из нескольких позиций, сохранение нулевой интенсивности, очистка при отмене выхода и пустые значения при закрытии на первом баре новой сессии.

Тест строки под графиком проверяет постоянные показания последнего завершённого бара и наведение на обе панели, знаки отклонения объёма от среднего, скрытие индикаторов открытого бара и сохранение высоты графика.

Тест таблицы позиций сверяет все её поля журнала с фактическим CSV после входа, закрытия и отмены выхода. Отдельно проверяется обновление открытого и закрытого PnL при нажатии клавиш.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_manual_backtest.py -v
```
