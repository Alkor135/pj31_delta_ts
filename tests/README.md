# Проверки графика Finam

`test_finam_delta_chart.py` создаёт временные дневные ZIP и вызывает расчёт из `finam_delta_bar_chart/chart.py`. Проверяется одно окно из 20 предыдущих будних сессий с тиками для разницы объёмов и порога дельты, в том числе при построении графика с субботы по понедельник. Остальные проверки охватывают пустые дни, недостаточную историю, совпадающие времена закрытия, смену сессии и частоту направленных сделок. Используется стандартная библиотека Python и локальное расчётное ядро.

Запуск из корня `pj31_delta_ts`. Параметр `-s` задаёт каталог тестов, `-p` выбирает файл, `-v` включает подробный вывод.

Тесты прогресса проверяют оба счётчика на диапазоне с пустым и отсутствующим архивами, а также расчёт оставшегося времени и его сброс в начале следующего этапа.

При отсутствии папки тиков или ZIP за выбранную дату проверяется полный путь в сообщении об ошибке при относительном `--input-root`.

Тесты дневного кэша создают базу рядом с временными ZIP. Они проверяют повторное открытие и выборку части диапазона без чтения тиков, возобновление прерванного расчёта, обновление разницы после изменения, добавления или удаления буднего ZIP и независимость буднего окна от воскресного архива. Отдельная проверка подтверждает, что старая запись пересчитывается и в SQLite сохраняется поле `volume_diff`.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_finam_delta_chart.py -v
```

`test_standalone_chart.py` переносит код графика во временный каталог и проверяет запуск с `--help` напрямую и через `python -m` без соседних проектов. Отдельная проверка имитирует `ru_RU` в дочерних процессах, измеряет долю высоты нижней панели в открытом окне Qt и сверяет цвета и расположение знаковых столбцов в экспортированном PNG на тестовых ZIP.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_standalone_chart.py -v
```

`test_manual_backtest.py` проверяет раскрытие свечей, команды окна Qt, входы и выходы на совпадающих временных метках, откат, защиту существующего CSV и повтор команды после ошибки сохранения. Для открытых позиций проверяются прибыль и убыток по текущему открытию и последнему закрытию, для закрытых — результат по цене выхода и его отмена. Проверки CSV сверяют разницу объёмов и обе интенсивности предыдущего завершённого бара и пустые значения при первом входе в новую сессию. На тестовых ZIP отдельно проверяется загрузка бэктеста из `src` при запуске `chart.py --backtest` напрямую и через `python -m`. Для проверки используются временные файлы и окно Qt в режиме без экрана.

Для `close_buy_rate` и `close_sell_rate` проверяются одновременный выход из нескольких позиций, сохранение нулевой интенсивности, очистка при отмене выхода и пустые значения при закрытии на первом баре новой сессии.

Тест строки под графиком проверяет постоянные показания последнего завершённого бара и наведение на обе панели, знаки разницы объёмов, цвета и высоты столбцов, нулевое значение без столбца, скрытие индикаторов открытого бара и сохранение высоты графика.

Тест таблицы позиций сверяет все её поля журнала с фактическим CSV после входа, закрытия и отмены выхода. Отдельно проверяется обновление открытого и закрытого PnL при нажатии клавиш.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_manual_backtest.py -v
```

`test_supertrend.py` сверяет уровни Supertrend с ручным расчётом ATR и обеими сменами направления. Проверка экспорта запускает `chart_2_supertrend.py` с заданными параметрами на временных дневных ZIP и ищет четыре цвета двух ступенчатых линий на ценовой панели PNG.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_supertrend -v
```

`test_cluster_volume.py` проверяет суммирование сделок по ценам и границам баров на временных ZIP. Тесты охватывают одинаковые метки времени, равные объёмы, дневной остаток, повторное чтение SQLite и пересчёт при изменении данных ZIP или границ. Проверка экспорта ищет синие точки в PNG и сверяет размещение обоих кэшей рядом.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_cluster_volume -v
```

`test_semafor.py` сверяет экстремумы CountZZ и смену последней метки с исходными примерами, проверяет Point, отключение уровня и направление заливки между SMA. Проверки на временных ZIP покрывают скрытый прогрев SMA и семафора, отсечение будущей даты, метки FXi, синий контур и обе заливки в PNG.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_semafor -v
```

`test_semafor_backtest.py` запускает окно Qt без экрана, проверяет появление экстремума на правильном шаге, откат метки с кольцом, кнопку легенды, отсутствие панели и столбца разницы объёмов, покупку и закрытие с записью PnL. Отдельные тесты сверяют чёрный разделитель при смене даты, закрытие выбранной строки и число дат с входами после закрытия и отката. Тест на временных ZIP проверяет старт и продолжение исходного диапазона со скрытым прогревом SMA после появления нового архива.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_semafor_backtest -v
```

`test_backtest_state.py` использует временные JSON и CSV для проверки восстановления точного шага и сделок, пересборки CSV и защиты от одновременного открытия. Отдельно проверяет отмену действия при сбое JSON, восстановление после блокировки CSV и отказ при изменении свечей.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_backtest_state -v
```
