Показатель SMA — доля случаев, когда опорный и пять следующих полных баров целиком остались с одной стороны SMA34. При одинаковом весе каждого закрытия внутри дня разница по SMA между утром и остальным временем меняет знак у обоих инструментов. При сравнении с одинаковым весом десятиминуток и требовании завершить все пять следующих баров в той же зоне у MIX получено 50,2 % против 42,3 %, у RTS — 53,1 % против 47,8 %.

  1. Из обеих таблиц chart_days прочитаны только данные 2026 года. Источники — C:\data_quote\delta_bar_finam_MIX\chart.sqlite3 и C:\data_quote\delta_bar_finam_RTS\chart.sqlite3. Московская дата определяет день недели. Декабрь в базах отсутствует.
  2. Как в графике проекта, SMA34 строится по закрытиям текущего и 33 предыдущих баров, с переносом истории через границу даты и включением дневных остатков в историю средней. До прогрева значения пропускаются. Для измерения берутся только бары с is_complete = 1. Касанием считается Low ≤ SMA ≤ High, включая тени и равенство. Серии и будущие окна прерываются на границе даты.
  3. Для каждого опорного полного бара с пятью последующими полными барами проверяется сохранение одной стороны SMA на всех шести барах. Касание на самом опорном баре также даёт ноль. Если в этот день пяти будущих баров нет, окно пропускается для обоих методов. Поэтому на малоликвидных сессиях и ближе к закрытию выборка смещена в сторону дат с большей активностью.
  4. На тех же наблюдениях ER = |C₅ − C₀| / (|C₁ − C₀| + … + |C₅ − C₄|). При пяти нулевых изменениях присваивается 0. Восходящие и нисходящие движения учитываются одинаково. Формула ER в документации TradingView.
  5. Для выбора времени сначала берётся среднее по опорным барам за каждые 10 минут каждой даты, затем среднее по доступным датам для этих же 10 минут. Для основного подбора нужны минимум 60 будних дат на интервал у каждого инструмента, включая хотя бы по 20 дат в январе–июне и июле–ноябре. Этому условию отвечают все 74 интервала с 09:00 до 21:20. При разбивке по дням недели внутри этой сетки нужны минимум 12 дат и по 4 в каждой части периода.
  6. Для каждого инструмента и каждого метода из значения каждой десятиминутки вычитается среднее её профиля по всем допущенным десятиминуткам. Выбирается непрерывный диапазон с наибольшей суммой таких отклонений. Так длительный период повышенных значений может включать локальные спады. Затем вычисляется пересечение диапазонов. Окончание округлено до следующей границы сетки.
  7. Для сравнения выбранного окна с остальным временем сначала усредняются значения доступных десятиминуток отдельно внутри и вне окна на каждой дате. Затем усредняются только парные даты. Для статистики фактической длительности каждая начавшаяся серия входит один раз. При расчёте часов начала и длительностей не требуется наличие пяти следующих баров.
