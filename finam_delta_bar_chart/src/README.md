# Вспомогательные модули графика Finam

| Модуль | Назначение |
| --- | --- |
| `finam_archives.py` | Поиск дневных ZIP в каталоге `--input-root` для выбранного инструмента. |
| `delta_core.py` | Чтение тиков, калибровка порога дельты и расчёт свечей. |
| `day_cache.py` | Чтение и запись рассчитанных дней в SQLite с проверкой архивов и версии расчёта. |
| `backtest.py` | Состояние ручного бэктеста и журнал позиций в CSV. |
| `backtest_window.py` | Окно Qt, раскрытие свечей и команды ручного бэктеста. |
| `finplot_compat.py` | Загрузка `finplot` с поддержкой русской локали без правок установленных файлов. |
| `__init__.py` | Размер окна исторических сессий и цвета, общие для графика и бэктеста. |

Модули загружает `chart.py`. Список параметров можно вывести из корня проекта.

```powershell
.\.venv\Scripts\python.exe .\finam_delta_bar_chart\chart.py --help
```
